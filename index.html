What is a postal code and how does it work?

Postal codes are location-based numeric or alphanumeric identifiers used by postal services to sort and deliver mail efficiently. India uses a 6-digit PIN code system, the United States uses ZIP codes, and the United Kingdom uses alphanumeric postcodes.
